# SiswaMed (E-Klinik Siswa) — Campus Health & Medical Leave System

**Course:** CSC584 - Enterprise Programming  
**Group:** Group 2 (ELITE)  
**Deliverable:** Phase 1 - Project Storyboard & Database ERD (Week 9)

## Project Overview
**SiswaMed** is a web-based campus clinic management system designed to streamline medical appointments, patient queue tracking, diagnosis updates, medical leave (MC) management, and student graduation record archiving. The system supports role-based views for **Students**, **Medical Officers**, and **Clinic Admins**.
